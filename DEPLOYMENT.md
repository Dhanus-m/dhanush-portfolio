# GitHub Pages deployment checklist

- [ ] Create a public GitHub repository for the portfolio.
- [ ] Upload `index.html`, `styles.css`, `app.js`, `portfolio.json`, `admin.html`, `README.md`, `DEPLOYMENT.md`, and `assets/`.
- [ ] Add `assets/profile.jpg` and update the `photo` value in `portfolio.json`.
- [ ] Add `assets/resume.pdf` and update the `resume` value in `portfolio.json`.
- [ ] Commit and push the files.
- [ ] Open repository Settings → Pages.
- [ ] Select Deploy from a branch, branch `main`, folder `/ (root)`.
- [ ] Save and wait for the published URL.
- [ ] Test desktop and mobile layouts, theme toggle, navigation, contact links, photo and resume download.
- [ ] Open `/admin.html`, make a harmless test edit, export JSON, and confirm it parses before replacing the live config.
